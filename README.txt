BOBBY & EVA — WEDDING INVITATION

CARA MENJALANKAN
1. Ekstrak folder BOBBY-EVA-WEDDING.
2. Buka folder tersebut di VS Code.
3. Jalankan index.html dengan Live Server atau letakkan folder di htdocs XAMPP.
4. Ganti foto pada assets/images/ sesuai nama file yang sudah tersedia.
5. Tambahkan musik MP3 dengan nama assets/music/song.mp3.

FOTO YANG DIGUNAKAN
- hero.jpeg : foto utama/prewedding
- bride.jpg : foto Eva
- groom.jpg : foto Bobby
- 1.jpeg : foto untuk Our Story
- 2.jpeg, 3.jpeg, 4.jpeg, 5.jpeg : foto galeri
- gift.jpg : foto wedding gift

DATA UNDANGAN
Edit js/config.js untuk nama, tanggal, jam, lokasi, rekening, dan pengaturan RSVP. Data yang belum tersedia tetap ditandai placeholder.

CATATAN TANGGAL
HTML sumber menyebut akad Jumat, 12 Desember 2026 dan resepsi Minggu, 20 Juni 2027. Kedua tanggal tersebut dipertahankan sesuai sumber. Countdown dan Google Calendar menggunakan tanggal utama/akad 12 Desember 2026. Periksa kembali tanggal sebelum publikasi.

RSVP
- Isi whatsappNumber di js/config.js dengan nomor admin format internasional tanpa tanda +; atau
- Isi googleScriptUrl dengan URL Web App Google Apps Script agar data RSVP dikirim ke Google Sheets.

DESAIN
Frame foto diterapkan pada foto hero, kedua foto pasangan, foto story, semua foto galeri, dan foto gift. Galeri dapat diklik untuk membuka lightbox. Tampilan responsif untuk desktop dan ponsel.
